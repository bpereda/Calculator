# Calculadora

## Descripción

Este proyecto es una calculadora web desarrollada como tarea en el marco de la asignatura de **Diseño de Aplicaciones Móviles**. El diseño está inspirado en la aplicación de calculadora de celular, replicando su interfaz y funcionalidad básica.

## Características

- Interfaz intuitiva similar a calculadoras móviles
- Operaciones básicas: suma, resta, multiplicación y división
- Diseño responsivo
- Implementación con HTML, CSS y JavaScript

## Estructura del Proyecto

```
Calculator/
├── index.html    # Estructura HTML de la calculadora
├── calculator.css     # Estilos y diseño de la interfaz
├── calculator.js      # Lógica y funcionalidad
└── README.md         # Documentación del proyecto
```

## Uso

Para utilizar la calculadora, simplemente abre el archivo `calculator.html` en tu navegador web.

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript

Desarrollo realizado como proyecto académico para la asignatura de Diseño de Aplicaciones Móviles.
